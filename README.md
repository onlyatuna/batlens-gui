# batlens-gui

Windows laptop battery tray tool. Uses [batlens-core](https://github.com/onlyatuna/batlens-core) for battery data.

Status: skeleton. The binary prints the current charge percent. The tray icon and popup panel are not implemented.

## Build

```
cargo build --release
```
